# Strava Photobook 撞色主题切换设计

日期：2026-09-18
状态：已确认

## 目标

在不削弱照片和活动叙事的前提下，为画册增加一个易发现、低干扰、可持久化的主题切换器。当前黑白橙视觉继续作为默认主题，用户可以在同一入口切换到 18 组指定撞色。切换必须即时生效，不刷新页面、不改变当前页，并在下次访问时恢复。

## 视觉方向

采用已确认的 A 方案：顶栏中的紧凑“主题”按钮打开色板弹层。界面保持克制的编辑画册气质，颜色作为结构和强调，而不是大面积装饰。

每个主题包含：

- `primary`：封面、封底、按钮激活态、深色界面与主要轮廓。
- `accent`：高光理由、当前主题标记、焦点状态和照片说明强调。
- `paper`：从主色生成的极浅纸张倾向，保证内页长文本可读。
- `accentInk`：根据撞色亮度选择黑或白，使标签文字维持足够对比。

照片本身不着色；照片说明继续使用深色渐变，只让 kicker 和少量强调响应 `accent`。路线、正文和统计使用主题化的中性色，避免高饱和颜色抢占信息层级。

## 组件与数据边界

### 主题目录

运行时新增一个独立主题目录模块，作为 19 个主题 ID、中文名称和颜色值的唯一事实来源。模块负责：

- 校验主题 ID；
- 计算 `accentInk`；
- 生成供 DOM 使用的 CSS 自定义属性；
- 为主题选择器输出有序条目。

主题目录不关心翻页状态和弹层行为，便于独立测试与未来增加主题。

### 主题选择器

顶栏右侧加入按钮，显示当前主题双色样和“主题”文字。弹层使用原生按钮网格，每项包含双色样、名称和选中标记。桌面端锚定顶栏右侧；窄屏端使用底部面板，最大高度受视口限制并允许内部滚动。

交互规则：

1. 点击触发按钮打开或关闭弹层。
2. 点击主题立即应用，但弹层保持打开，便于快速比较。
3. 点击弹层外、按 `Esc` 或再次点击触发按钮关闭。
4. 打开后焦点进入当前主题；关闭后焦点回到触发按钮。
5. 使用原生 Tab 顺序；选中项提供 `aria-pressed=true`，弹层和触发按钮保持正确的 `aria-expanded` 状态。

### 应用与持久化

主题应用到根元素的 `data-theme` 和一组 CSS 自定义属性。所有需要换色的规则只引用变量，不为 19 个主题复制整套 CSS。

存储键固定为 `strava-photobook.theme`。初始化顺序：

1. 读取本地存储；
2. 值存在且属于主题目录时恢复；
3. 值无效、存储不可用或脚本异常时回退 `editorial`；
4. 主题状态不写入 URL，也不改变当前翻页位置。

为了减少首屏闪色，文档头部在主样式加载前执行一个很短的恢复脚本，只设置已校验的主题 ID；完整交互仍由运行时脚本接管。禁用 JavaScript 时使用默认主题，画册和翻页前的静态内容仍可阅读。

## 颜色应用范围

- 页面背景、顶栏文字、状态与按钮：使用主题变量形成统一外框。
- 封面、封底：以 `primary` 为主体，`accent` 用于小型几何标记或副标题强调。
- 纸张页：使用极浅 `paper`，正文继续使用高对比深色。
- 高光活动：理由标签使用 `accent` + `accentInk`；头像徽标与路线终点响应主题。
- 照片页：渐变保持深色，kicker 使用 `accent`，保证不同照片上均可读。
- 选择器：当前项使用主题自己的主/撞色边框，不依赖颜色作为唯一状态，另有勾选和 `aria-pressed`。

## 响应式与边界

桌面弹层不覆盖顶栏标题，宽度容纳两列或三列主题条目。手机端面板固定在安全区上方，占用不超过视口高度的 55%，主题网格至少两列，每个按钮点击区域不小于 44px。

切换主题只改变颜色变量，不改字体尺寸、间距或页几何，因此已有的文字防溢出与路线分栏不变量继续成立。弹层本身使用 `overflow:auto`，长主题名称允许换行但不得超出按钮。

## 测试与验收

自动化测试覆盖：

- 目录准确包含默认主题和 18 组指定主题，名称、顺序和十六进制颜色完全一致；
- 默认主题为 `editorial`；
- 有效存储值恢复，无效值回退默认；
- 切换主题写入存储、更新根属性和选中状态，不改变当前页；
- 弹层的打开、关闭、外部点击和 `Esc` 行为；
- 选择器具有可访问名称、`aria-expanded`、`aria-pressed` 和足够的触控尺寸；
- 主题变量被封面、活动理由、照片 kicker、按钮与路线终点实际引用；
- 现有 Python、Node 页面契约、静态布局门禁和生成流程保持通过。

浏览器验收至少检查默认主题、深色+亮色撞色、红色+浅色撞色和低饱和主题各一组，分别在桌面 `1440×1000` 与手机 `390×844` 验证弹层、切换、刷新恢复、翻页保持和文字边界。最后重新发布 GitHub Pages，并从公网验证主题目录、选择器和持久化代码已生效。
