# 年度活动轨迹热力图设计

## 目标

在封面之后、活动内容之前加入一页年度轨迹热力图。它必须来自当年真实 Strava `summary_polyline`，随画册主题换色，并保持纯静态、无需地图服务或额外密钥。

## 方案选择

采用全年轨迹聚合 SVG，而不是日历格子或在线地图。日历格子只能表达频率，在线底图会引入密钥、网络依赖和隐私边界；聚合 SVG 能直接表达骑行空间分布，适合 GitHub Pages，也与现有单次活动路线图复用同一解码逻辑。

## 页面与信息结构

- 封面后的左页继续使用年度标题页。
- 右页为 `Annual activity heatmap`，在首个跨页完整呈现。
- 页面仅展示“年度轨迹”、有轨迹活动数、总里程和覆盖月份，避免说明文字抢占地图。
- 没有任何可解码轨迹时不插入页面，避免空白或无效页。

## 渲染方式

所有轨迹共同投影到一个年度包围盒。SVG 绘制两层同路径：低透明度、较宽的主色底层形成路网；较细的强调色上层形成热点。路线重复经过同一区域时通过透明度叠加自然增强。路径数量保持与有效活动数一致，不引入外部瓦片或运行时请求。

## 主题与可访问性

SVG 使用 `var(--theme-primary)` 与 `var(--theme-accent)`，主题切换立即生效。页面提供可读的 `aria-label`，装饰性 SVG 对辅助技术隐藏。文本和图形均限制在页面安全区，移动端沿用画册的单页缩放。

## 验证

- 单元测试验证多轨迹聚合、非法轨迹忽略及空数据降级。
- 页面测试验证位置、数据摘要和主题变量。
- 布局门禁验证地图边界、溢出隐藏和主题色引用。
- 发布校验要求：当候选活动数据含轨迹时，成品必须包含年度热力图标记。
